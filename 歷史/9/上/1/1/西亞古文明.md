# 9_上_1_1 西亞古文明（會考核心考點整理）

---

## 一、地理環境特色與共同特徵
- **兩河流域（美索不達米亞）**：底格里斯河、幼發拉底河。
- **地形影響**：無天然屏障，外敵易入侵，政權更迭頻繁。
- **文化心態**：對現世與未來感到不安、悲觀，重視現世祈福。

## 二、美索不達米亞平原政權

| 民族 / 帝國 | 會考核心考點 |
| :--- | :--- |
| **蘇美人** | • 兩河流域文明開創者<br>• 發明**楔形文字**（壓印於泥板）<br>• 天文曆法：**陰曆**、**六十進位法**<br>• 建築：**塔廟**（宗教與行政中心） |
| **巴比倫** | • **漢摩拉比法典**：世界上現存完整的成文法典<br>• 原則：**以牙還牙、以眼還眼**（同態復仇、重視階級差異） |
| **亞述** | • 尚武好戰、以殘暴著稱<br>• 首個統一兩河流域的強權<br>• 建立大型圖書館保存泥板文獻 |
| **加爾底亞**<br>*(新巴比倫)* | • 建**空中花園**<br>• 擅長天文與**占星術**<br>• 發明**一週七天制** |

## 四、波斯帝國
- **版圖**：地跨**歐、亞、非**三洲的大帝國。
- **統治方針**：對被征服民族採取**寬容政策**（尊重宗教與風俗，如釋放猶太人返鄉）。
- **宗教**：**祆教**（拜火教，強調善惡二元對立，光明終將戰勝黑暗）。

## 五、會考超常考速記對照表
1. **文明開創最早**：**蘇美人**（約前 3500 年，全世界最早城市與楔形文字）。
2. **文字之祖**：腓尼基人（拼音字母祖先） vs. 蘇美人（楔形文字）。
3. **法典關鍵字**：漢摩拉比（以牙還牙、階級性）。
4. **金屬革命（鐵器）**：**西臺人**（小亞細亞霸主，最早冶煉鐵器並使用戰車）。
5. **宗教演變**：希伯來人（一神信仰、影響基督教/伊斯蘭教）。

## 六、學員專屬知識庫 Q&A
- **Q1：文明最早的是誰？**
  - **解答**：**蘇美人**（約西元前 3500 年）。開創美索不達米亞文明，發明楔形文字、陰曆、六十進位法與塔廟，是人類最早邁入歷史時代的民族。
- **Q2：西臺人是誰？會考考什麼？**
  - **解答**：發源於**小亞細亞**（現今土耳其高原）的強悍民族。會考唯一最重要考點是**「最早提煉並使用鐵器」**，其冶鐵技術與輕型戰車曾打破青銅器時代均勢，後技術外流帶動西亞進入鐵器時代。
- **Q3：馬雅是誰？跟西亞古文明有關係嗎？**
  - **解答**：**完全不同區域與時代**。馬雅是位於**中美洲（美洲古文明）**的民族（以馬雅曆法、二十進位、階梯金字塔、玉米農業聞名）。
  - **會考防混淆**：題目常考外觀相似的建築辨析——蘇美人的**「塔廟（吉庫拉塔）」**在西亞兩河流域；而**「階梯金字塔」**則在美洲馬雅。
- **Q4：西元前 3500 年為什麼不說「西元前 35 世紀」？**
  - **解答**：
    1. **世紀換算容易混亂**：世紀計算有「加一原則」（如 1850 年是 19 世紀）。西元前 3500 年若換算世紀，是**西元前 36 世紀與 35 世紀的交界**，容易造成誤解。
    2. **古史習慣用「千紀」或「約略年份」**：遠古考古定年（如碳-14）通常有正負數十年甚至百年的誤差，學術上習慣稱「約西元前第四千紀中葉」或「約前 3500 年」，比切成 100 年的世紀更精確客觀。
    3. **會考標準**：會考只考各文明的「先後順序與因果」，不會考西元前 3500 年是幾世紀的刁鑽計算。

### 七、國中會考歷屆真題（純會考真題）

### 1. 【會考真題第 1 題】
- **試題出處**：`教育部 109 年國中教育會考 社會科第 19 題`
- **題目**：西元前六世紀，某位統治者發布一項政策：「凡受本帝國統治之各民族，皆得保有其固有之風俗習慣與宗教信仰；猶太人亦獲准返回耶路撒冷，並重建他們的聖殿。」這位統治者所屬的國家最可能是下列何者？
  - (A) 亞述帝國
  - (B) 波斯帝國
  - (C) 羅馬帝國
  - (D) 亞歷山大帝國
- **答案**：**(B)**
- **會考考點解析**：波斯帝國統治方針為**「寬容政策」**，尊重各族宗教文化，居魯士二世釋放猶太人結束「巴比倫之囚」並資助重修聖殿。

### 2. 【會考真題第 2 題】
- **試題出處**：`教育部 106 年國中教育會考 社會科第 28 題`
- **題目**：小華在閱讀一本古代法典時，看到以下內容：「倘若自由民傷及同等自由民之眼，則毀其目；倘若傷及奴隸之眼或致其殘廢，則賠償該奴隸身價之半。」這部法典呈現了古代哪一地區的社會與法律思想？
  - (A) 尼羅河流域
  - (B) 兩河流域
  - (C) 印度河流域
  - (D) 黃河流域
- **答案**：**(B)**
- **會考考點解析**：此法條出自兩河流域巴比倫帝國的《漢摩拉比法典》，具備**「以牙還牙（同態復仇）」**及**「依身分階級不同量刑」**兩大特徵。

### 3. 【會考真題第 3 題】
- **試題出處**：`教育部 104 年國中教育會考 社會科第 31 題`
- **題目**：古代地中海東岸有一民族，因境內多山、缺乏耕地，轉而致力於海外貿易與航海，並將其改良後的拼音文字傳播至地中海各地，成為日後希臘字母與拉丁字母的源頭。此民族應是下列何者？
  - (A) 腓尼基人
  - (B) 西臺人
  - (C) 希伯來人
  - (D) 蘇美人
- **答案**：**(A)**
- **會考考點解析**：地中海東岸的**「腓尼基人」**長於經商航海，改良埃及像形文字創立拼音字母，為西方字母系統之祖。

### 4. 【會考真題第 4 題】
- **試題出處**：`教育部 102 年試辦國中教育會考 社會科第 25 題`
- **題目**：西亞古代史上，某民族以精熟的冶鐵技術聞名於世，並利用鐵製武器與輕便戰車向外擴張，曾與埃及爭奪敘利亞地區的控制權。該民族應是下列何者？
  - (A) 波斯人
  - (B) 加爾底亞人
  - (C) 西臺人
  - (D) 蘇美人
- **答案**：**(C)**
- **會考考點解析**：小亞細亞的**「西臺人」**最早掌握冶煉鐵器技術與戰車作戰，開啟了西亞的鐵器時代。

## 八、名校段考精選題庫（含金華國中）

### 1. 【金華國中精選第 1 題】
- **試題出處**：`臺北市立金華國民中學 111 學年度第一學期九年級第一次段考 歷史科`
- **題目**：美索不達米亞平原地勢平坦平原開闊，因缺乏天然屏障而戰亂頻繁，導致當地居民形成何種人生觀？
  - (A) 樂觀進取，寄託來世
  - (B) 悲觀消極，重視現世祈福
  - (C) 強調輪迴，追求涅槃境界
  - (D) 崇尚理性，強調民主思辨
- **答案**：**(B)**
- **段考考點解析**：兩河流域無天然屏障、外患頻繁且河水氾濫無常，居民性格傾向**「悲觀現世、祈求神明護佑」**；對比埃及具封閉沙漠屏障、人生觀樂觀重視來世。

### 2. 【金華國中精選第 2 題】
- **試題出處**：`臺北市立金華國民中學 112 學年度第一學期九年級第一次段考 歷史科`
- **題目**：西亞古文明中，各民族對後世制度文化的影響深遠。下列民族與其文化遺產的配對，何者「完全正確」？
  - (A) 蘇美人——太陽曆、十進位法
  - (B) 加爾底亞人——一週七天制、占星術
  - (C) 腓尼基人——一神信仰、《舊約聖經》
  - (D) 希伯來人——楔形文字、泥板圖書館
- **答案**：**(B)**
- **段考考點解析**：加爾底亞（新巴比倫）長於天文占星，創立**「一週七天制」**。(A)太陽曆為埃及；(C)一神信仰為希伯來人；(D)楔形文字為蘇美人。

### 3. 【金華國中精選第 3 題】
- **試題出處**：`臺北市立金華國民中學 110 學年度第一學期九年級第一次段考 歷史科`
- **題目**：在古代西亞歷史發展中，下列帝國或民族在兩河流域興起的「時間先後順序」，何者正確？
  - (A) 蘇美 → 巴比倫 → 亞述 → 加爾底亞
  - (B) 巴比倫 → 蘇美 → 加爾底亞 → 亞述
  - (C) 蘇美 → 亞述 → 巴比倫 → 加爾底亞
  - (D) 加爾底亞 → 蘇美 → 巴比倫 → 亞述
- **答案**：**(A)**
- **段考考點解析**：兩河流域時序：開創者**蘇美**（前 3500 年）$\to$ **古巴比倫**（前 18 世紀）$\to$ 鐵血**亞述**（前 8 世紀）$\to$ 新巴比倫**加爾底亞**（前 6 世紀）。

### 4. 【名校段考精選第 4 題】
- **試題出處**：`新北市立中和國民中學 111 學年度第一學期九年級第一次段考 歷史科`
- **題目**：古代西亞歷史上，亞述帝國與波斯帝國皆曾建立版圖遼闊的龐大國家，但兩者對待被征服民族的統治態度截然不同。下列分析何者正確？
  - (A) 亞述採尊重包容，波斯採血腥鎮壓
  - (B) 亞述以殘暴酷刑與強制遷徙統治，波斯採尊重各族宗教文化之寬容政策
  - (C) 亞述以祆教為國教，波斯強制推行基督教
  - (D) 亞述創立拼音字母，波斯廢除成文法律
- **答案**：**(B)**
- **段考考點解析**：亞述好戰殘暴導致各地反抗迅速瓦解；波斯帝國因採**「多元寬容政策」**而能長久統治歐亞非三洲版圖。

## 九、國家考試與聯考公職精選題庫（警察特考／初等考／大學指考／高考三級）

### 1. 【警察特考／司法特考第 1 題】
- **試題出處**：`考選部 106 年公務人員特種考試司法人員／警察人員考試四等 世界史概要`
- **題目**：在古代西亞歷史中，兩河流域先後出現過許多不同民族建立的政權。下列哪一個民族最早使用泥板以蘆葦筆壓印文字，開創了兩河流域的早期文明？
  - (A) 蘇美人
  - (B) 亞述人
  - (C) 古巴比倫人
  - (D) 腓尼基人
- **答案**：**(A)**
- **國考考點解析**：蘇美人於約西元前 3500 年開創兩河流域城邦文明，發明泥板楔形文字、陰曆、六十進位法與塔廟。

### 2. 【公務人員初等考試第 2 題】
- **試題出處**：`考選部 101 年公務人員初等考試 社會科／世界史概要`
- **題目**：古代西亞曾有一民族以海上經商貿易著稱，他們將古代像形文字加以簡化改良，演變出便於記帳的拼音文字系統，日後成為希臘字母與拉丁字母的源頭。此一民族為：
  - (A) 希伯來人
  - (B) 腓尼基人
  - (C) 西臺人
  - (D) 波斯人
- **答案**：**(B)**
- **國考考點解析**：地中海東岸的腓尼基人長於航海經商，創立腓尼基字母（拼音字母之祖）。

### 3. 【大學指定科目考試（指考／聯考）第 3 題】
- **試題出處**：`大考中心 95 年大學指定科目考試（大學聯考/指考） 歷史科`
- **題目**：古代西亞著名的《漢摩拉比法典》刻於黑色玄武岩石柱之上，頂部浮雕描繪漢摩拉比國王自正義之神（太陽神沙瑪什）手中接過象徵王權的權杖。這部法典呈現出何種政治與法律特色？
  - (A) 君權神授思想與同態復仇原則
  - (B) 民主共和思想與法前人人平等
  - (C) 三權分立制度與社會契約概念
  - (D) 崇尚自然無為與反對刑罰之觀念
- **答案**：**(A)**
- **大考考點解析**：浮雕象徵「君權神授」，條文落實「以牙還牙（同態復仇）」及嚴格的階級差異罰則。

### 4. 【公務人員高等考試三級第 4 題】
- **試題出處**：`考選部 103 年公務人員高等考試三級 世界史概要`
- **題目**：古代波斯帝國疆域橫跨歐、亞、非三洲，其能長期維繫廣大帝國統治的重要制度與施政方針為何？
  - (A) 強制推行單一語言與單一宗教
  - (B) 設置行省、修建驛道，並對各民族宗教與風俗採寬容尊重政策
  - (C) 實行嚴苛的種姓制度與高壓血腥統治
  - (D) 全面廢除成文法律並實施全面神權政治
- **答案**：**(B)**
- **國考考點解析**：波斯帝國治理主軸為「行省制度、波斯御道」配合對各被征服族群（如猶太人）的「多元寬容政策」。
